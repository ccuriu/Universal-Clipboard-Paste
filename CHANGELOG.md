# Changelog

## 1.0.0 — 2026-09-25
- Полностью убрана привязка к ChatGPT и браузеру из рабочего пути.
- Ctrl+Shift+V теперь глобально вызывает обычную вставку Ctrl+V в активное поле.
- Удалены меню вложений, UI Automation, временные файлы и системный диалог выбора.
- Исправлено описание структуры INPUT для 64-битной Windows; SendInput теперь возвращает 4/4.
- Добавлен резервный keybd_event.
- Добавлен автозапуск HKCU Run.
- Автотест Блокнота с кириллицей пройден; обработка 24–29 мс.
