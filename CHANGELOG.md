# Changelog

## 1.1.0 — 2026-09-25
- Восстановлена исходная цель проекта: большой текст вставляется как компактное файловое вложение.
- Убраны меню ChatGPT, UI Automation, клики мышью и системный диалог выбора файла.
- Добавлен настоящий Shell IDataObject через SHCreateDataObject + OleSetClipboard.
- Добавлен OleFlushClipboard: файл доступен целевому приложению немедленно и не зависит от STA-потока.
- Ctrl+V отправляется прямо в активное поле.
- Исходный текст возвращается в буфер через неблокирующий Win32 clipboard restore.
- Payload-файлы автоматически очищаются и не участвуют ни в каком поиске.
- Реальные тесты ChatGPT: содержимое совпадает, кириллица сохранена, Ctrl/Shift отпущены, fallback=False.
- Три последовательных прогона: 183/185/193 мс.

## 1.0.0 — переходная версия
- Ctrl+Shift+V ошибочно был сведён к обычному Ctrl+V.
- Исправлена x64-структура INPUT и добавлен автозапуск.
- Сохранена как исторический этап; больше не является целевой архитектурой.

## 0.3.x — архив
- Старый ChatGPT-специфичный путь через меню вложений и файловый диалог.
