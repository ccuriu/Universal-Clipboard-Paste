# Changelog

## 0.3.0 — 2026-09-25
- Удалён медленный поиск созданного файла среди элементов системного диалога.
- Полный путь к файлу передаётся сразу в поле «Имя файла».
- Добавлен быстрый BM_CLICK с резервным способом открытия.
- Старые clipboard_*.txt удаляются перед созданием нового файла.
- Добавлена блокировка повторного Ctrl+Shift+V, пока предыдущая вставка не завершилась.
- Сохранены исправления для нового чата и экранной клавиатуры Windows.

## До 0.3.0
