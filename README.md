# Universal Clipboard Paste

Небольшая Windows-утилита: глобальная комбинация Ctrl+Shift+V превращается в обычную вставку Ctrl+V в текущее активное поле.

## Версия 1.0.0
- Не зависит от ChatGPT, Chrome, структуры веб-страницы или системного окна выбора файла.
- Работает в обычных полях ввода любых программ, где работает Ctrl+V.
- Не создаёт временные файлы и не открывает никаких окон.
- Исправлена 64-битная структура Windows INPUT; SendInput реально отправляет 4 события.
- Есть резервная отправка через keybd_event.
- При развёртывании автоматически добавляется в автозапуск текущего пользователя.

## Проверка
Автоматический тест в Блокноте: PASS, включая кириллицу.
Внутренняя задержка зарегистрированного срабатывания: 24–29 мс.

## Сборка и установка
BUILD.cmd собирает dist\ChatGPTClipboardFilePaste.exe.
deploy.ps1 собирает, заменяет рабочую копию, прописывает автозапуск и запускает программу.

Рабочая копия: %LOCALAPPDATA%\ChatGPTClipboardFilePaste
Журнал: %LOCALAPPDATA%\ChatGPTClipboardFilePaste\hotkey.log

Старая ChatGPT-специфичная реализация 0.3.1 сохранена в src\legacy.
