# Universal Clipboard Paste

Windows-утилита для компактной передачи большого текста: Ctrl+Shift+V превращает текст из буфера обмена во временный .txt и вставляет его как файловое вложение прямо в активное поле.

## Версия 1.1.0
- Не привязана к ChatGPT, Chrome или конкретной структуре сайта.
- Использует нативный Windows Shell IDataObject и OLE Clipboard — так же, как копирование файла из Проводника.
- Не открывает меню «+», Проводник или диалог выбора файла.
- Не использует UI Automation, координаты мыши и поиск имени файла.
- После вставки возвращает исходный текст в буфер обмена.
- Payload-файл удаляется автоматически; старые payload-файлы очищаются при запуске/следующих операциях.
- SendInput имеет корректную x64-структуру и резервный keybd_event.

## Проверено
В ChatGPT Web файл прикрепляется напрямую в поле.
Содержимое UTF-8 и кириллица совпадают с исходным текстом.
Ctrl/Shift после операции не зажаты.
Три последовательных теста: 183, 185 и 193 мс полного цикла; fallback=False; буфер восстановлен.

## Ограничение
Приложение должно уметь принимать файл, скопированный из Проводника, через Ctrl+V. Версия 1.1.0 преобразует только текстовый буфер в .txt. Изображения и уже скопированные файлы — следующий этап.

## Сборка и установка
BUILD.cmd собирает dist\ChatGPTClipboardFilePaste.exe.
deploy.ps1 заменяет рабочую копию, прописывает автозапуск и запускает программу.
Рабочая копия: %LOCALAPPDATA%\ChatGPTClipboardFilePaste
Журнал: %LOCALAPPDATA%\ChatGPTClipboardFilePaste\hotkey.log
