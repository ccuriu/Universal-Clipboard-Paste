# Universal Clipboard Paste

Universal Clipboard Paste — небольшая фоновая Windows-утилита для глобальной комбинации `Ctrl+Shift+V`, которая помогает аккуратно вставлять содержимое буфера обмена в поля ввода.

## Зачем это нужно

Обычный `Ctrl+V` вставляет скопированный текст прямо в поле. Это удобно для коротких фрагментов, но с длинными текстами быстро появляются проблемы: поле ввода превращается в огромную простыню, сложно дописать собственный комментарий, а исходный материал и ваш текст смешиваются в одно сообщение.

Universal Clipboard Paste решает это иначе: если в буфере находится текст, программа временно превращает его в обычный `.txt`-файл и вставляет этот файл через стандартный Windows Clipboard.

В результате длинный скопированный материал остаётся отдельным вложением, а поле ввода остаётся свободным для вашего сообщения, пояснения, вопроса или комментария.

Например, можно:
- скопировать длинную статью, лог, отчёт, переписку, инструкцию или фрагмент документа;
- прикрепить этот текст одним нажатием `Ctrl+Shift+V`, не заполняя им всё поле ввода;
- ниже отдельно написать, что именно нужно сделать с материалом;
- оставить комментарий к скопированному тексту, не смешивая исходник и собственные слова;
- переносить большие текстовые блоки между приложениями в более аккуратной и удобной форме;
- использовать одну и ту же комбинацию для текста, файлов и изображений без привязки к конкретной программе.

## Как работает

Программа использует стандартный Clipboard Windows и не привязана к конкретному приложению.

Поведение зависит от содержимого буфера:
- **текст** → временный UTF-8 `.txt` → вставка как файловое вложение;
- **файл или несколько файлов** → вставка исходного Clipboard без изменений;
- **изображение** → вставка исходного Clipboard без изменений;
- **другие форматы** → passthrough без преобразования.

Это работает в любых полях и приложениях, которые поддерживают соответствующую вставку из Clipboard.

## Версия 1.2.1

- без автоматизации интерфейса целевых приложений;
- без кликов мышью и координат;
- без системного окна выбора файла;
- без сохранения содержимого Clipboard в журнал;
- без записи названий активных окон в журнал;
- временные текстовые payload-файлы создаются только в системном `%TEMP%` и удаляются автоматически.

## Установка

Для обычного пользователя предназначен установщик `UniversalClipboardPaste-Setup-1.2.1.exe`.

Скачивайте готовую сборку со страницы **Releases**:
`https://github.com/ccuriu/Universal-Clipboard-Paste/releases/latest`

Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\UniversalClipboardPaste` и не требует прав администратора.

Установщик версии 1.2.1 пока не подписан коммерческим code-signing сертификатом, поэтому Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 с файлом `.sha256.txt`, приложенным к релизу.

Подробности: `docs/INSTALL.md`.

## Сборка из исходников

Требования:
- Windows x64 с .NET Framework 4.x;
- Inno Setup 6 для сборки установщика.

Сборка приложения:

`BUILD.cmd`

Сборка установщика:

`ISCC.exe installer.iss`

Результаты сборки помещаются в локальную папку `dist`, которая намеренно не хранится в Git.

## Безопасность и приватность

Политика: `SECURITY.md`.

Программа не должна сохранять содержимое Clipboard, названия активных окон или пользовательские пути в журнал. Временный текст используется только через системный `%TEMP%`.
