# Security Policy

## Supported version

The current release is supported.

## Reporting a vulnerability

Please open a GitHub issue that describes the security or privacy concern without including passwords, tokens, private keys, personal documents, clipboard contents, or other sensitive data.

If reproducing the problem would require sharing sensitive information, provide only a minimal sanitized reproduction.

## Privacy

Universal Clipboard Paste does not intentionally log clipboard contents, active window titles, or user document paths.

Temporary text payloads are created under the current user's system temporary directory and are removed automatically.
