# Архитектура 1.0

Программа регистрирует глобальную горячую клавишу Ctrl+Shift+V через RegisterHotKey.
Получив WM_HOTKEY, она ждёт отпускания модификаторов, принудительно нормализует Ctrl/Shift и отправляет Ctrl+V через SendInput.

## Надёжность
INPUT содержит MOUSEINPUT и KEYBDINPUT в union, поэтому Marshal.SizeOf соответствует Win32 INPUT и на x64 равен корректному размеру.
Если SendInput отправил не все четыре события, используется резервный keybd_event.
Mutex не допускает второй экземпляр программы, а Busy не допускает наложение двух срабатываний.

## Что намеренно отсутствует
Нет распознавания ChatGPT, поиска элементов интерфейса, мышиных кликов, временных .txt и файловых диалогов.
Это уменьшает задержку и число точек отказа на порядок.
