# Первое указание рабочему чату проекта

Работай только от текущей версии 1.0.0. Старую 0.3.x не возвращать в основной путь без отдельного решения управляющего чата.

Источник истины: src\ChatGPTClipboardFilePaste.cs, deploy.ps1 и hotkey.log установленной программы.

Задача:
1. Провести ручную матрицу проверки Ctrl+Shift+V: ChatGPT, адресная строка/обычное поле браузера, Блокнот, ещё одно настольное приложение.
2. Для каждого случая проверить правильность текста, отсутствие зажатых Ctrl/Shift и строку PASTE_SENT count=4.
3. Зафиксировать время elapsed_ms и любые приложения, где вставка отличается от обычного Ctrl+V.
4. Не добавлять UI Automation и обходы конкретных сайтов: универсальность — основной архитектурный принцип.
5. Любую новую сложность добавлять только после воспроизводимого теста, который показывает необходимость.
