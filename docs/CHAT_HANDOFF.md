# Задание новому чату-разработчику

Ты — исполнитель по проекту ChatGPTClipboardFilePaste. Управляющий чат принимает архитектурные решения и ведёт приоритеты.

Не начинай проект заново. Источник истины — текущий исходник src\ChatGPTClipboardFilePaste.cs и журнал установленной версии в %LOCALAPPDATA%\ChatGPTClipboardFilePaste\hotkey.log.

Первое задание:
1. Проверить версию 0.3.0 на нескольких реальных вставках Ctrl+Shift+V в существующем и новом чате ChatGPT.
2. Для каждого теста посчитать HOTKEY → FILE_DIALOG и FILE_DIALOG → ATTACHMENT_CONFIRMED.
3. Подтвердить, что в %TEMP%\ChatGPT_Paste после каждой вставки остаётся только свежий clipboard_*.txt.
4. Проверить отсутствие зажатых Shift/Ctrl и корректный возврат экранной клавиатуры.
5. Если полный цикл стабильно больше 2 секунд, локализовать задержку по журналу и предложить минимальную правку без ухудшения надёжности.
6. Ничего не переписывать целиком и не менять рабочий протокол без измерений.
