# Правила разработки

Источник истины — текущая ветка main и версия 1.2.1.

Основной путь:
- text -> UTF-8 payload -> Shell IDataObject -> OLE Clipboard -> Ctrl+V -> восстановление текста;
- files/image/other -> passthrough исходного Clipboard.

Не добавлять привязку к конкретным приложениям без воспроизводимой технической необходимости.
Не использовать UI Automation, мышиные клики или файловые диалоги в основном пути.
Не сохранять в лог содержимое Clipboard, названия активных окон, абсолютные пользовательские пути или иные персональные данные.

После изменений проверять:
- text-as-file;
- passthrough файлов;
- passthrough изображения;
- count=4 и fallback=False;
- отсутствие зажатых Ctrl/Shift;
- установку, автозапуск и удаление.
