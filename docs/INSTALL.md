# Установка Universal Clipboard Paste 1.2.0

## Для обычного пользователя
1. Запустить UniversalClipboardPaste-Setup-1.2.0.exe.
2. Пройти обычный мастер установки.
3. После завершения программа работает в фоне.
4. Скопировать нужное содержимое и нажать Ctrl+Shift+V.

Установка выполняется для текущего пользователя и не требует прав администратора.
Каталог: %LOCALAPPDATA%\UniversalClipboardPaste.
Программа автоматически запускается при входе в Windows.

## Что делает Ctrl+Shift+V
Текст прикрепляется как .txt.
Файлы, изображения и другие поддерживаемые Clipboard-форматы передаются как есть.

## Удаление
Использовать «Uninstall Universal Clipboard Paste» в меню Пуск
или стандартный раздел установленных приложений Windows.
Uninstaller останавливает процесс и удаляет автозапуск, payload и рабочий каталог.
