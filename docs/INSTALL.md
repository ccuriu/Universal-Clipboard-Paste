# Установка

## Готовый релиз

1. Скачайте `UniversalClipboardPaste-Setup-1.2.1.exe` из GitHub Releases.
2. Запустите установщик.
3. Завершите мастер установки.
4. Программа автоматически запускается в фоне и добавляется в автозапуск текущего пользователя.

Права администратора не требуются.

Рабочий каталог:

`%LOCALAPPDATA%\UniversalClipboardPaste`

Служебные файлы стандартного деинсталлятора хранятся отдельно:

`%LOCALAPPDATA%\UniversalClipboardPasteUninstall`

## Сборка установщика самостоятельно

1. Запустите `BUILD.cmd`.
2. Установите Inno Setup 6, если он ещё не установлен.
3. Выполните `ISCC.exe installer.iss`.
4. Готовый установщик появится в локальной папке `dist`.

Папка `dist` является build-output и не хранится в Git.

## Использование

Скопируйте нужное содержимое и нажмите Ctrl+Shift+V.

- текст будет передан как .txt;
- файлы будут вставлены без преобразования;
- изображения будут вставлены без преобразования;
- остальные поддерживаемые Clipboard-форматы передаются как есть.

## Удаление

Используйте стандартный раздел установленных приложений Windows или пункт `Uninstall Universal Clipboard Paste` в меню Пуск.

Удаление останавливает процесс, удаляет автозапуск, временные файлы из `%TEMP%`, журнал, рабочий каталог и служебный каталог деинсталлятора.
