# Состояние проекта

Текущая версия: 0.3.0.

Главная цель: максимально быстрая и надёжная вставка текста из буфера в ChatGPT как .txt по Ctrl+Shift+V.

## Подтверждённая причина прежней задержки
Системный диалог появлялся примерно за 0,15 с, но поиск файла через UI Automation занимал 8,7–9,6 с.

## Что уже исправлено
- Поиск файла в списке удалён.
- Полный путь передаётся прямо в поле «Имя файла».
- Старые временные clipboard_*.txt удаляются перед созданием нового.
- Повторное срабатывание блокируется до завершения текущей операции.
- Сохранены исправления для нового чата, ProseMirror, фокуса и экранной клавиатуры.
