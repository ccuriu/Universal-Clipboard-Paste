# Состояние проекта

Текущая рабочая версия: 1.1.0.

## Подтверждённый принцип
Ctrl+Shift+V берёт текстовый Clipboard, создаёт временный UTF-8 .txt, публикует его как настоящий Windows Shell IDataObject и отправляет Ctrl+V прямо в активное поле.

## Проверено 25.09.2026
- ChatGPT Web принимает файл напрямую, без меню вложений.
- Payload полностью совпадает с исходным текстом, включая кириллицу.
- Исходный текст возвращается в Clipboard.
- Ctrl и Shift после операции не зажаты.
- SendInput: count=4, fallback=False.
- Первый контрольный цикл: 315 мс.
- Три последовательных цикла: 183, 185 и 193 мс; BUSY_SKIPS=0.
- Автозапуск HKCU Run сохранён.

## Что снято с основного пути
UI Automation, мышиные клики, кнопка «+», файловый диалог и поиск файла по имени.
