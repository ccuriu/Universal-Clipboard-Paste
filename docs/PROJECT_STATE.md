# Состояние проекта

Текущая рабочая версия: 1.0.0.

## Принцип
Ctrl+Shift+V — глобальная горячая клавиша. Утилита освобождает Ctrl/Shift и отправляет Ctrl+V в активное окно.

## Проверено
- Глобальный перехват действительно срабатывает.
- SendInput: 4/4 событий, fallback=False.
- Блокнот получает точную строку с кириллицей.
- Измеренная внутренняя задержка: 24–29 мс.
- Автозапуск UniversalClipboardPaste записан в HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

## Почему прежняя архитектура снята
Она зависела от структуры ChatGPT, положения меню, экранной клавиатуры и системного диалога выбора файла.
Кроме того, структура INPUT была неполной для x64, поэтому SendInput мог возвращать 0.
